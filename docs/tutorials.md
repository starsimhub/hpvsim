These tutorials walk through how to use HPVsim. Work through them in order if you are new: each one builds on the last, and each runs end to end as written.

Every code block on these pages is executed when the documentation is built, so what you read is what the current version produces. To run them yourself, install HPVsim (`pip install hpvsim`) and copy the blocks into a script or a notebook of your own.

- [T1 - Getting started](tutorials/tut_intro.qmd)
- [T2 - Plotting, printing, and saving](tutorials/tut_plotting.qmd)
- [T3 - Running scenarios](tutorials/tut_running.qmd)
- [T4 - People, populations, and networks](tutorials/tut_people.qmd)
- [T5 - Using interventions](tutorials/tut_interventions.qmd)
- [T6 - Using analyzers](tutorials/tut_analyzers.qmd)
- [T7 - Calibration](tutorials/tut_calibration.qmd)
- [T8 - HIV co-infection](tutorials/tut_hiv.qmd)
- [T9 - HPV latency](tutorials/tut_latency.qmd)

Once you are comfortable with the workflow, the [user guide](user-guide/index.qmd) explains how each part of the model works and how to change it.
