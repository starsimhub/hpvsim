These tutorials walk through how to use HPVsim. If you want to explore them interactively, you can run them on Binder via [http://tutorials.hpvsim.org](http://tutorials.hpvsim.org). To run locally, start a Jupyter environment in the `docs/tutorials` folder. You can use either `jupyter lab` or `jupyter notebook` to run these tutorials.

- [Introduction](tutorials/tut_intro.qmd)
- [Plotting](tutorials/tut_plotting.qmd)
- [Running simulations](tutorials/tut_running.qmd)
- [People and population](tutorials/tut_people.qmd)
- [Interventions](tutorials/tut_interventions.qmd)
- [Analyzers](tutorials/tut_analyzers.qmd)
- [Calibration](tutorials/tut_calibration.qmd)
